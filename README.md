# ayurvedic_search_engine

This project is a simple web application that allows users to search for Ayurvedic medicines based on symptoms or diseases. The application provides suggestions dynamically as the user types, making it easy to find remedies.

## Features

- Search input for diseases or symptoms
- Autocomplete functionality for suggestions
- Dynamic filtering of results based on user input
- Mobile-friendly and responsive design

## Project Structure

```
ayurvedic-remedy-app
├── src
│   ├── index.html        # Main HTML document
│   ├── styles.css       # CSS styles for the website
│   ├── app.js           # JavaScript for handling user interactions
│   └── data
│       └── remedies.json # Predefined dataset of Ayurvedic remedies
└── README.md            # Project documentation
```

## Getting Started

To run the Ayurvedic Remedy App locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd ayurvedic-remedy-app
   ```

2. **Open the `index.html` file in your web browser:**
   You can simply double-click the `index.html` file or use a local server to serve the files.

3. **Start searching:**
   Type in the search bar to find Ayurvedic remedies based on symptoms or diseases.
